# FidesLayer

FidesLayer helps teams make AI systems observable, testable, and governable.

We are building a practical layer for defining systems and flows, running validations, and keeping the evidence and reports needed to understand how AI behaves in production.

- 🌐 [Visit FidesLayer](https://app.fideslayer.com)
- 📚 [Read the documentation](https://docs.fideslayer.com)
- 🐛 [Report an issue](https://github.com/fideslayer/fideslayer/issues)
