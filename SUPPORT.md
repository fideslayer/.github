# Support

For usage questions and troubleshooting:

1. Check the relevant repository README and the [FidesLayer documentation](https://docs.fideslayer.com).
2. Search existing GitHub issues.
3. Open a new issue in the repository that owns the behavior, including reproduction steps, expected behavior, actual behavior, and relevant logs with secrets removed.

For security concerns, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
