# Contributing to FidesLayer

Thanks for helping improve FidesLayer.

## Before you start

1. Read the repository README and any local contribution notes.
2. Search existing issues and pull requests before opening a new one.
3. For larger changes, open an issue first so the scope and approach can be discussed.

## Pull requests

- Keep changes focused and explain the user impact.
- Add or update tests and documentation where relevant.
- Do not include secrets, credentials, or production data.
- Describe verification steps and any known limitations.

Maintainers may ask for changes to preserve compatibility, security, and a clear project boundary.
